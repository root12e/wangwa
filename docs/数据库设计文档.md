# 数据库设计文档

## 1. 数据库概述

### 1.1 数据库选择
- **主数据库**: MySQL 8.0+
- **缓存数据库**: Redis 7+
- **文件存储**: MinIO

### 1.2 设计原则
- 遵循第三范式
- 合理使用索引提升查询性能
- 考虑数据扩展性
- 保证数据一致性和完整性

## 2. 数据表设计

### 2.1 用户管理相关表

#### 2.1.1 用户表 (users_user)
```sql
CREATE TABLE users_user (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(150) UNIQUE NOT NULL,
    email VARCHAR(254) UNIQUE NOT NULL,
    first_name VARCHAR(150),
    last_name VARCHAR(150),
    is_active TINYINT(1) DEFAULT 1,
    is_staff TINYINT(1) DEFAULT 0,
    is_superuser TINYINT(1) DEFAULT 0,
    date_joined TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP NULL,
    phone VARCHAR(20),
    avatar VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 2.1.2 角色表 (users_role)
```sql
CREATE TABLE users_role (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) UNIQUE NOT NULL,
    description TEXT,
    permissions JSON,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 2.1.3 用户角色关联表 (users_user_roles)
```sql
CREATE TABLE users_user_roles (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT,
    role_id INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, role_id),
    FOREIGN KEY (user_id) REFERENCES users_user(id) ON DELETE CASCADE,
    FOREIGN KEY (role_id) REFERENCES users_role(id) ON DELETE CASCADE
);
```

### 2.2 组织架构相关表

#### 2.2.1 部门表 (organization_department)
```sql
CREATE TABLE organization_department (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    description TEXT,
    parent_id INT,
    manager_id INT,
    status VARCHAR(20) DEFAULT 'active',
    sort_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (parent_id) REFERENCES organization_department(id) ON DELETE SET NULL,
    FOREIGN KEY (manager_id) REFERENCES users_user(id) ON DELETE SET NULL
);
```

#### 2.2.2 店铺表 (organization_store)
```sql
CREATE TABLE organization_store (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    department_id INT,
    manager_id INT,
    address TEXT,
    phone VARCHAR(20),
    email VARCHAR(254),
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (department_id) REFERENCES organization_department(id) ON DELETE CASCADE,
    FOREIGN KEY (manager_id) REFERENCES users_user(id) ON DELETE SET NULL
);
```

### 2.3 产品管理相关表

#### 2.3.1 产品分类表 (product_category)
```sql
CREATE TABLE product_category (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    parent_id INT,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (parent_id) REFERENCES product_category(id) ON DELETE SET NULL

```

#### 2.3.2 产品表 (product_product)
```sql
CREATE TABLE product_product (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    category_id INT,
    store_id INT,
    description TEXT,
    specifications JSON,
    unit VARCHAR(50),
    price DECIMAL(10,2),
    cost_price DECIMAL(10,2),
    image_url VARCHAR(500),

```

#### 2.3.3 产品图片表 (product_product_image)
```sql
CREATE TABLE product_product_image (
    id INT AUTO_INCREMENT PRIMARY KEY,

    alt_text VARCHAR(200),
    sort_order INT DEFAULT 0,

    FOREIGN KEY (product_id) REFERENCES product_product(id) ON DELETE CASCADE

```

### 2.4 库存管理相关表

#### 2.4.1 库存表 (inventory_inventory)
```sql
CREATE TABLE inventory_inventory (
    id INT AUTO_INCREMENT PRIMARY KEY,
    product_id INT,
    store_id INT,
    current_quantity INT DEFAULT 0,
    min_quantity INT DEFAULT 0,
    max_quantity INT,
    reserved_quantity INT DEFAULT 0,
    available_quantity INT DEFAULT 0,
    last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE(product_id, store_id),
    FOREIGN KEY (product_id) REFERENCES product_product(id) ON DELETE CASCADE,
    FOREIGN KEY (store_id) REFERENCES organization_store(id) ON DELETE CASCADE
);
```

#### 2.4.2 库存变动记录表 (inventory_inventory_transaction)
```sql
CREATE TABLE inventory_inventory_transaction (
    id INT AUTO_INCREMENT PRIMARY KEY,
    inventory_id INT,
    transaction_type VARCHAR(50) NOT NULL,
    quantity INT NOT NULL,
    before_quantity INT NOT NULL,
    after_quantity INT NOT NULL,
    reference_type VARCHAR(50),
    reference_id INT,
    notes TEXT,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (inventory_id) REFERENCES inventory_inventory(id) ON DELETE CASCADE,
    FOREIGN KEY (created_by) REFERENCES users_user(id) ON DELETE SET NULL
);
```

#### 2.4.3 库存盘点表 (inventory_inventory_check)
```sql
CREATE TABLE inventory_inventory_check (
    id INT AUTO_INCREMENT PRIMARY KEY,
    store_id INT,
    check_date DATE NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    total_items INT DEFAULT 0,
    checked_items INT DEFAULT 0,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (store_id) REFERENCES organization_store(id) ON DELETE CASCADE,
    FOREIGN KEY (created_by) REFERENCES users_user(id) ON DELETE SET NULL
);
```

#### 2.4.4 库存盘点明细表 (inventory_inventory_check_detail)
```sql
CREATE TABLE inventory_inventory_check_detail (
    id INT AUTO_INCREMENT PRIMARY KEY,
    check_id INT,
    product_id INT,
    expected_quantity INT NOT NULL,
    actual_quantity INT NOT NULL,
    difference INT NOT NULL,
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (check_id) REFERENCES inventory_inventory_check(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES product_product(id) ON DELETE CASCADE
);
```

### 2.5 预警系统相关表

#### 2.5.1 预警规则表 (alert_alert_rule)
```sql
CREATE TABLE alert_alert_rule (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    rule_type VARCHAR(50) NOT NULL,
    threshold_value DECIMAL(10,2) NOT NULL,
    comparison_operator VARCHAR(10) NOT NULL,
    store_id INT,
    product_id INT,
    department_id INT,
    notification_methods JSON,
    is_active TINYINT(1) DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (store_id) REFERENCES organization_store(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES product_product(id) ON DELETE SET NULL,
    FOREIGN KEY (department_id) REFERENCES organization_department(id) ON DELETE SET NULL
);
```

#### 2.5.2 预警记录表 (alert_alert_record)
```sql
CREATE TABLE alert_alert_record (
    id INT AUTO_INCREMENT PRIMARY KEY,
    rule_id INT,
    alert_type VARCHAR(50) NOT NULL,
    alert_level VARCHAR(20) NOT NULL,
    message TEXT NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    resolved_at TIMESTAMP NULL,
    resolved_by INT,
    notification_sent TINYINT(1) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (rule_id) REFERENCES alert_alert_rule(id) ON DELETE CASCADE,
    FOREIGN KEY (resolved_by) REFERENCES users_user(id) ON DELETE SET NULL
);
```

## 3. 索引设计

### 3.1 主要索引
```sql
-- 用户表索引
CREATE INDEX idx_users_user_email ON users_user(email);
CREATE INDEX idx_users_user_username ON users_user(username);

-- 部门表索引
CREATE INDEX idx_organization_department_code ON organization_department(code);
CREATE INDEX idx_organization_department_parent_id ON organization_department(parent_id);
CREATE INDEX idx_organization_department_manager_id ON organization_department(manager_id);

-- 店铺表索引
CREATE INDEX idx_organization_store_code ON organization_store(code);
CREATE INDEX idx_organization_store_department_id ON organization_store(department_id);
CREATE INDEX idx_organization_store_manager_id ON organization_store(manager_id);

-- 产品表索引
CREATE INDEX idx_product_product_code ON product_product(code);
CREATE INDEX idx_product_product_category_id ON product_product(category_id);
CREATE INDEX idx_product_product_store_id ON product_product(store_id);

-- 库存表索引
CREATE INDEX idx_inventory_inventory_product_store ON inventory_inventory(product_id, store_id);
CREATE INDEX idx_inventory_inventory_store_id ON inventory_inventory(store_id);

-- 库存变动记录索引
CREATE INDEX idx_inventory_transaction_inventory_id ON inventory_inventory_transaction(inventory_id);
CREATE INDEX idx_inventory_transaction_created_at ON inventory_inventory_transaction(created_at);
CREATE INDEX idx_inventory_transaction_reference ON inventory_inventory_transaction(reference_type, reference_id);

-- 预警记录索引
CREATE INDEX idx_alert_record_status ON alert_alert_record(status);
CREATE INDEX idx_alert_record_created_at ON alert_alert_record(created_at);

-- 采购需求索引
CREATE INDEX idx_purchase_request_store_id ON purchase_purchase_request(store_id);
CREATE INDEX idx_purchase_request_status ON purchase_purchase_request(status);
CREATE INDEX idx_purchase_request_requester_id ON purchase_purchase_request(requester_id);

-- 操作日志索引
CREATE INDEX idx_operation_log_user_id ON system_operation_log(user_id);
CREATE INDEX idx_operation_log_created_at ON system_operation_log(created_at);
CREATE INDEX idx_operation_log_action ON system_operation_log(action);
```

## 4. 数据关系图

### 4.1 主要实体关系
- **部门** ←→ **店铺** (一对多)
- **部门** ←→ **用户** (多对多，通过manager_id)
- **店铺** ←→ **产品** (一对多)
- **店铺** ←→ **用户** (多对多，通过manager_id)
- **产品** ←→ **库存** (一对一)
- **产品** ←→ **库存变动记录** (一对多)
- **产品** ←→ **采购需求明细** (一对多)
- **产品** ←→ **采购订单明细** (一对多)
