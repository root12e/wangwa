# 旺蛙科技产品库存后台管理系统项目计划书

## 1. 项目概述

### 1.1 项目名称
旺蛙科技产品库存后台管理系统

### 1.2 项目背景
随着公司业务规模的不断扩大，传统的库存管理方式已无法满足现代化管理的需求。需要建立一个高效、智能的库存管理系统，实现库存的实时监控、预警管理和采购流程的数字化。

### 1.3 项目目标
- 建立完整的库存管理体系，实现部门-店铺-产品的三级管理
- 实现库存实时监控和预警机制
- 建立完整的采购流程管理体系
- 提供数据统计和分析功能
- 实现库存数据的自动化更新

### 1.4 项目范围
- 部门管理模块
- 店铺管理模块
- 产品管理模块
- 库存管理模块
- 预警系统模块
- 采购管理模块
- 数据统计模块
- 系统管理模块

## 2. 技术架构

### 2.1 后端技术栈
- **框架**: Django 4.2+
- **数据库**: MySQL 8.0+
- **缓存**: Redis 7+
- **消息队列**: Celery + Redis
- **API框架**: Django REST Framework
- **认证**: JWT (JSON Web Token)
- **权限管理**: Django Guardian
- **任务调度**: Celery Beat
- **日志**: Django Logging + ELK Stack
- **监控**: Prometheus + Grafana

### 2.2 前端技术栈
- **框架**: Vue 3.3+
- **构建工具**: Vite 4+
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **UI组件库**: Element Plus
- **HTTP客户端**: Axios
- **图表库**: ECharts 5+
- **代码规范**: ESLint + Prettier
- **类型检查**: TypeScript 5+

### 2.3 数据库设计
- **主数据库**: MySQL (业务数据)
- **缓存数据库**: Redis (会话、缓存、队列)
- **文件存储**: MinIO (图片、文档存储)

### 2.4 部署和运维
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx
- **进程管理**: Supervisor
- **CI/CD**: GitLab CI/CD
- **监控**: Prometheus + Grafana + AlertManager
- **日志收集**: ELK Stack (Elasticsearch + Logstash + Kibana)

## 3. 系统架构设计

### 3.1 整体架构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   前端Vue3      │    │   Django后端    │    │   数据库层      │
│                 │◄──►│                 │◄──►│                 │
│  Element Plus   │    │  DRF API        │    │  MySQL          │
│  ECharts        │    │  Celery         │    │  Redis          │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                                ▼
                       ┌─────────────────┐
                       │   外部系统      │
                       │                 │
                       │   扣子工作流    │
                       │   QQ邮箱       │
                       └─────────────────┘
```

### 3.2 数据模型设计
- **部门(Department)**: 部门信息、直接负责人
- **店铺(Store)**: 店铺信息、所属部门、运营负责人
- **产品(Product)**: 产品信息、所属店铺、库存信息
- **库存(Inventory)**: 库存记录、变动历史
- **用户(User)**: 系统用户、角色权限
- **采购需求(PurchaseRequest)**: 采购申请、状态跟踪
- **采购订单(PurchaseOrder)**: 采购订单、供应商信息
- **预警记录(Alert)**: 库存预警、处理状态

## 4. 功能模块详细设计

### 4.1 部门管理模块
- **功能描述**: 管理公司各部门信息
- **主要功能**:
  - 部门增删改查
  - 部门直接负责人设置
  - 部门下店铺列表查看
  - 部门数据统计

### 4.2 店铺管理模块
- **功能描述**: 管理各部门下的店铺信息
- **主要功能**:
  - 店铺增删改查
  - 店铺运营负责人设置
  - 店铺产品列表管理
  - 店铺库存汇总

### 4.3 产品管理模块
- **功能描述**: 管理店铺下的产品信息
- **主要功能**:
  - 产品增删改查
  - 产品图片管理
  - 产品分类管理
  - 产品库存设置

### 4.4 库存管理模块
- **功能描述**: 核心库存管理功能
- **主要功能**:
  - 库存实时监控
  - 库存变动记录
  - 库存预警设置
  - 库存盘点功能

### 4.5 预警系统模块
- **功能描述**: 库存预警和通知
- **主要功能**:
  - 库存预警规则设置
  - QQ邮箱预警通知
  - 预警处理状态跟踪
  - 预警历史记录

### 4.6 采购管理模块
- **功能描述**: 采购流程管理
- **主要功能**:
  - 采购需求提交
  - 采购需求审核
  - 采购订单管理
  - 采购状态跟踪

### 4.7 数据统计模块
- **功能描述**: 数据分析和报表
- **主要功能**:
  - 库存统计报表
  - 销售数据分析
  - 采购数据分析
  - 趋势图表展示

### 4.8 系统管理模块
- **功能描述**: 系统配置和用户管理
- **主要功能**:
  - 用户权限管理
  - 系统参数配置
  - 操作日志记录
  - 数据备份恢复

## 6. 技术实现要点

### 6.1 库存实时更新
- 使用Celery异步任务处理扣子工作流数据
- Redis缓存热点库存数据
- WebSocket实现库存实时推送
- 数据库事务确保数据一致性

### 6.2 预警机制
- 定时任务检查库存状态
- 多级预警规则配置
- QQ邮箱SMTP集成
- 预警处理流程管理

### 6.3 权限管理
- 基于角色的访问控制(RBAC)
- JWT token认证
- 细粒度权限控制
- 操作日志记录

### 6.4 数据安全
- 数据加密存储
- API访问频率限制
- SQL注入防护
- XSS攻击防护

## 7. 风险评估与应对

### 7.1 技术风险
- **风险**: 扣子工作流接口不稳定
