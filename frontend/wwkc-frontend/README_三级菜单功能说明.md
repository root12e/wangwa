# 三级菜单功能说明

## 概述

本项目在 `App.vue` 中实现了完整的三级菜单系统，提供了更好的导航体验和功能组织。

## 菜单结构

### 一级菜单（主导航）
- 仪表盘
- 库存管理
- 用户管理
- 店铺管理
- 部门管理
- **Etsy管理** (可展开)
- 消息和聊天室
- 系统设置

### 二级菜单（Etsy管理分组）
- 产品管理
- 订单管理
- 生产管理
- 物流管理
- 财务管理
- 店铺信息

### 三级菜单（具体功能页面）
每个二级分组下包含具体的功能页面：

#### 产品管理
- 产品登记表
- 设计需求表

#### 订单管理
- 订单导入汇总表
- 订单统计表

#### 生产管理
- 采购需求表
- 生产需求表

#### 物流管理
- 配货发货表
- 二维码标签表

#### 财务管理
- 云途导出表
- 云途扣费表

#### 店铺信息
- 店铺信息表

## 技术实现

### 菜单配置
菜单结构通过 `menuConfig` 数组进行配置，支持以下类型：

```typescript
interface MenuItem {
  key: string;           // 唯一标识
  icon?: Component;      // 图标组件
  label: string;         // 显示标签
  path?: string;         // 路由路径（仅链接类型）
  type: 'link' | 'group'; // 菜单类型
  children?: MenuItem[]; // 子菜单项
}
```

### 状态管理
- `expandedMenus`: 控制菜单展开状态
- `sidebarCollapsed`: 控制侧边栏折叠状态

### 核心函数
- `toggleMenu(menuKey)`: 切换菜单展开/收起
- `isMenuExpanded(menuKey)`: 检查菜单是否展开
- `isRouteActive(path)`: 检查路由是否激活

## 样式特性

### 响应式设计
- 支持侧边栏折叠/展开
- 移动端适配
- 平滑的过渡动画

### 视觉层次
- 一级菜单：主要导航项
- 二级菜单：分组标题
- 三级菜单：具体功能项
- 清晰的缩进和分隔线

### 交互反馈
- 悬停效果
- 激活状态高亮
- 展开/收起动画

## 使用方法

### 添加新菜单项
1. 在 `menuConfig` 中添加新的配置
2. 确保路由配置正确
3. 添加相应的图标和标签

### 自定义样式
可以通过修改CSS变量来调整：
- 颜色主题
- 间距大小
- 字体大小
- 动画效果

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 注意事项

1. 菜单展开状态在页面刷新后会重置
2. 侧边栏折叠时，三级菜单会自动隐藏
3. 确保所有路由路径都正确配置
4. 图标组件需要从 `@element-plus/icons-vue` 导入
