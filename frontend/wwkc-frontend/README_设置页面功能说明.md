# 设置页面功能说明

## 概述
设置页面已经全面升级，新增了丰富的个性化配置选项，包括语言切换、主题设置、字体配置、布局调整等PC端常用功能。

## 新增功能

### 1. 外观设置
- **主题模式切换**：支持浅色、深色、跟随系统三种模式
- **预设主题**：提供5种精美预设主题（默认、海洋、森林、日落、午夜）
- **自定义颜色**：可自定义主色调、强调色、背景色、文字色、边框色
- **实时预览**：所有颜色修改都能实时预览效果

### 2. 字体设置
- **字体大小**：支持小(14px)、中(16px)、大(18px)、特大(20px)四种尺寸
- **字体族选择**：支持Inter、微软雅黑、苹方、思源黑体等常用字体
- **行高调整**：可调整行高从1.2到2.0
- **字间距控制**：支持-2px到5px的字间距调整
- **字重选择**：支持细体、正常、粗体三种字重

### 3. 语言设置
- **多语言支持**：支持简体中文、English、日本語、한국어四种语言
- **语言预览**：实时预览不同语言下的界面文本
- **国旗标识**：每种语言都有对应的国旗emoji标识

### 4. 布局设置
- **侧边栏配置**：可调整侧边栏宽度(200-300px)和默认折叠状态
- **内容区域**：可调整内容内边距(16-48px)
- **界面元素**：可控制面包屑、页面标题、紧凑模式等显示选项

### 5. 通知设置
- **多种通知方式**：声音提醒、桌面通知、邮件通知
- **通知类型**：系统通知、库存预警、订单状态
- **免打扰时间**：可设置免打扰时间段

### 6. 性能设置
- **自动刷新**：支持数据自动刷新，可设置刷新间隔
- **懒加载**：图片懒加载优化
- **缓存管理**：可控制缓存启用和过期时间

### 7. 辅助功能
- **高对比度**：提高界面对比度，便于阅读
- **减少动画**：减少界面动画，适合敏感用户
- **屏幕阅读器**：支持屏幕阅读器访问
- **键盘导航**：完整的键盘导航支持
- **焦点指示器**：清晰的焦点指示
- **色盲支持**：为色盲用户提供特殊颜色方案

### 8. 数据设置
- **数据保留**：可设置数据保留天数(30-1095天)
- **导出格式**：支持Excel、CSV、JSON三种导出格式
- **导入验证**：数据导入时的验证选项
- **备份频率**：支持每日、每周、每月备份
- **数据同步**：可配置数据同步间隔

## 技术特性

### 1. 响应式设计
- 支持各种屏幕尺寸
- 移动端友好的界面布局
- 触摸友好的操作体验

### 2. 实时应用
- 设置修改立即生效
- 无需刷新页面
- 平滑的过渡动画

### 3. 本地存储
- 所有设置自动保存到localStorage
- 页面刷新后设置保持不变
- 支持设置导入导出

### 4. 主题系统
- CSS变量驱动的主题系统
- 支持深色模式
- 可扩展的主题架构

## 使用方法

### 1. 快速切换主题
1. 进入"外观设置"标签页
2. 选择预设主题或自定义颜色
3. 设置立即生效

### 2. 调整字体
1. 进入"字体设置"标签页
2. 选择合适的字体大小和字体族
3. 微调行高和字间距

### 3. 切换语言
1. 进入"语言设置"标签页
2. 从下拉菜单选择目标语言
3. 界面语言立即切换

### 4. 导入导出设置
1. 在页面底部找到"全局操作"区域
2. 点击"导出所有设置"保存当前配置
3. 点击"导入设置"恢复之前保存的配置

## 注意事项

1. **浏览器兼容性**：建议使用现代浏览器（Chrome 80+、Firefox 75+、Safari 13+）
2. **存储空间**：设置会占用少量localStorage空间
3. **性能影响**：某些设置（如高对比度、减少动画）可能影响界面性能
4. **主题切换**：深色主题在某些老旧显示器上可能显示效果不佳
